## 2. Latar Belakang Aplikasi

Perkembangan teknologi informasi dan komunikasi telah mengubah cara masyarakat memperoleh informasi dan menjalankan berbagai aktivitas sehari-hari. Kehadiran internet dan perangkat digital seperti smartphone memungkinkan masyarakat mengakses informasi dengan lebih cepat dan praktis. **Berdasarkan survei APJII tahun 2026, penetrasi internet di Indonesia telah mencapai 81,72%. Perkembangan ini turut memengaruhi cara masyarakat mencari dan mengikuti berbagai kegiatan atau event, seperti konser, festival, seminar, workshop, dan kegiatan komunitas.** Selain menjadi sarana hiburan dan edukasi, penyelenggaraan event juga dapat membuka peluang bagi berbagai pihak, mulai dari penyelenggara acara, pekerja kreatif, pelaku seni, vendor, hingga pelaku Usaha Mikro, Kecil, dan Menengah (UMKM). Berdasarkan laporan Kementerian Pariwisata mengenai penyelenggaraan Karisma Event Nusantara (KEN) 2025, kegiatan tersebut mencatat sekitar **12,2 juta pengunjung**, melibatkan **135.148 tenaga kerja**, serta melibatkan **20.877 pelaku UMKM**. Selain itu, total dampak ekonomi yang dihasilkan mencapai sekitar **Rp23,76 triliun**. Data tersebut menunjukkan bahwa penyelenggaraan event memiliki potensi untuk menggerakkan aktivitas ekonomi dan memberikan peluang bagi berbagai sektor pendukung.

Meskipun teknologi digital telah mempermudah penyebaran informasi, informasi mengenai event masih sering tersebar di berbagai media, seperti media sosial, website penyelenggara, dan platform penjualan tiket, sehingga pengguna perlu mengakses beberapa sumber untuk memperoleh informasi secara lengkap. Selain itu, perbedaan lokasi geografis dapat menjadi kendala bagi masyarakat yang ingin mengikuti event secara langsung. Padahal, saat ini event dapat diselenggarakan secara online maupun offline sehingga masyarakat dari kota atau pulau yang berbeda tetap memiliki kesempatan untuk berpartisipasi. Berdasarkan kondisi tersebut, **VENMART dikembangkan sebagai aplikasi mobile yang membantu masyarakat menemukan informasi dan mengakses berbagai event melalui satu platform**. Aplikasi ini dirancang untuk memudahkan pengguna memperoleh informasi kegiatan, membaca berita terkait event, serta memantau aktivitas dan status transaksi. Dengan demikian, VENMART diharapkan dapat memberikan kemudahan dalam menemukan event sesuai minat dan kebutuhan sekaligus memperluas jangkauan informasi kegiatan kepada calon peserta dari berbagai wilayah.

## 3. Tujuan Pengembangan

Pengembangan aplikasi VENMART memiliki beberapa tujuan, yaitu:

1. Mempermudah masyarakat dalam menemukan dan memperoleh informasi mengenai berbagai event melalui satu platform.
2. Membantu pengguna menemukan kegiatan yang sesuai dengan minat dan kebutuhan berdasarkan informasi event yang tersedia.
3. Memberikan akses informasi mengenai event online maupun offline agar pengguna dari berbagai wilayah tetap dapat menemukan kegiatan yang dapat diikuti.
4. Menyediakan informasi dan berita terkait kegiatan atau event sebagai untuk membantu pengguna dalam memperoleh informasi terkait event, serta sebagai media promosi bagi penyelenggara event untuk memperkenalkan, mempublikasikan, dan meningkatkan jangkauan informasi event kepada calon pengunjung maupun tenant.

## 4. Target Pengguna

VENMART ditujukan kepada masyarakat yang memiliki ketertarikan untuk mencari informasi dan mengikuti berbagai kegiatan atau event, baik secara online maupun offline.

| Aspek | Karakteristik |

| Geografis |Masyarakat dari berbagai wilayah, baik dalam negeri maupun luar negeri, termasuk pengguna yang berada di luar wilayah penyelenggaraan event dan ingin memperoleh informasi atau berpartisipasi dalam kegiatan yang tersedia. |

| Perilaku | Individu yang memanfaatkan perangkat smartphone dan jaringan internet untuk memperoleh informasi, mencari kegiatan, mempromosikan event, menemukan maupun mempunyai usaha, serta berpartisipasi dalam berbagai kegiatan sesuai minat dan kebutuhan. |

## 5. Deskripsi Aplikasi

VENMART merupakan aplikasi marketplace berbasis mobile yang bertujuan untuk membantu pengguna dalam pada pencarian informasi dan akses terhadap berbagai event. Aplikasi ini dirancang untuk menjadi platform yang memudahkan pengguna dalam menemukan kegiatan, memperoleh informasi terkait event, serta melihat aktivitas yang berkaitan dengan penggunaan aplikasi. 

Melalui aplikasi VENMART ini, pengguna dapat menjelajahi berbagai informasi event, membaca berita terbaru, melihat riwayat aktivitas, dan mengelola informasi profil. Event yang tersedia dapat memiliki metode pelaksanaan online maupun offline sehingga pengguna dapat memilih kegiatan berdasarkan kebutuhan dan kondisi geografis masing-masing. Dengan menggabungkan informasi event, berita, dan aktivitas pengguna dalam satu aplikasi, VENMART diharapkan dapat memberikan pengalaman yang lebih praktis dan terstruktur dalam mencari serta mengikuti berbagai kegiatan.

## 6. Permasalahan

Berdasarkan latar belakang tersebut, terdapat beberapa permasalahan yang menjadi dasar pengembangan aplikasi VENMART, diantaranya:

1. Informasi mengenai event masih ditemukan melalui berbagai media, seperti media sosial, website penyelenggara, dan platform penjualan tiket. Hal ini membuat pengguna perlu mengakses beberapa sumber untuk memperoleh informasi kegiatan secara lengkap.

2. Banyaknya kegiatan dengan kategori, jadwal, lokasi, dan harga yang berbeda dapat menyulitkan pengguna dalam menemukan event yang sesuai dengan minat dan kebutuhannya.

3. Pengguna yang tinggal jauh dari lokasi penyelenggaraan event dapat mengalami kendala untuk mengikuti kegiatan secara langsung. Oleh karena itu, informasi mengenai metode pelaksanaan event, baik online maupun offline, menjadi penting bagi pengguna.

4. Penyelenggara membutuhkan sarana digital untuk memperkenalkan kegiatan kepada calon peserta dari berbagai wilayah agar informasi event dapat menjangkau masyarakat secara lebih luas.

5. Pengguna membutuhkan informasi yang jelas mengenai aktivitas pemesanan atau transaksi event, seperti status Paid, Pending, Refunded, dan Completed, agar aktivitas tersebut dapat dipantau dengan lebih mudah.

## 7. Fitur Aplikasi

### 1 Home
Halaman Home merupakan halaman utama aplikasi yang menampilkan informasi dan rekomendasi event kepada pengguna agar dapat menemukan kegiatan yang menarik dengan lebih mudah.

### 2 News dan Detail News
Fitur News menyediakan informasi dan berita yang berkaitan dengan berbagai kegiatan. Pengguna dapat mencari berita, melihat kategori berita, serta membaca informasi secara lebih lengkap melalui halaman detail berita. Sedangkan, halaman detail news berfungsi untuk menampilkan informasi berita secara lengkap setelah pengguna memilih salah satu berita dari halaman News.

### 3 Activity
Fitur Activity digunakan untuk menampilkan riwayat aktivitas pengguna yang berkaitan dengan transaksi atau pemesanan event. Informasi aktivitas dikelompokkan berdasarkan status berikut:

- **Paid:** Menampilkan aktivitas dengan status pembayaran berhasil.
- **Pending:** Menampilkan aktivitas yang masih menunggu penyelesaian pembayaran.
- **Refunded:** Menampilkan aktivitas yang telah melalui proses pengembalian dana.
- **Completed:** Menampilkan aktivitas yang telah selesai dilaksanakan.

### 4 Profile dan Edit Profile
Fitur Profile digunakan untuk menampilkan informasi akun pengguna serta memberikan akses menuju halaman pengeditan profil. Selain itum fitur edit profile dapat membantu pengguna mengubah informasi profil yang tersedia pada aplikasi sesesuai dengan kebutuhan.

## 9. Cara Instalasi

### Prasyarat

Pastikan perangkat telah memiliki:
- Node.js
- npm
- Git
- Visual Studio Code (disarankan)
- Expo Go atau Android Emulator

### Langkah Instalasi

**1. Clone Repository**

```bash
git clone https://github.com/Kirana0219/venmart.git
```

**2. Masuk ke Direktori Proyek**

```bash
cd venmart
```

**3. Install Dependencies**

```bash
npm install
```

**4. Jalankan Aplikasi**

```bash
npx expo start
```

**5. Buka Aplikasi**

Setelah Expo berhasil dijalankan, pengguna dapat memindai QR Code melalui Expo Go jika kompatibel dengan versi proyek atau menjalankan aplikasi melalui Android Emulator.
